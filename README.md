# Browser Desktop

一个基于 Electron 的现代桌面浏览器，目标是对标 Chrome 的核心体验，并提供：

- 漂亮的沉浸式界面
- 标签页浏览
- 本地 HTML / HTM / PDF 打开
- 主题切换
- Chrome / Edge 插件扩展入口
- Windows 优先支持

## 运行

```bash
npm install
npm start
```
